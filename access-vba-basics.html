Basic Math Operators

Operator Meaning Examples
+ Addition x = 2 + 3 ' 5
- Subtraction / Negation x = 10 - 4 ' 6
x = -5
* Multiplication x = 6 * 7 ' 42
/ Division (returns Double) x = 5 / 2 ' 2.5
\ Integer division x = 5 \ 2 ' 2
Mod Remainder x = 5 Mod 2 ' 1
^ Power x = 2 ^ 3 ' 8
& String concatenation full = "Loc" & " " & "Ha"
Tip: if you use + with strings, VBA may try to coerce values and can surprise you. Prefer & for joining strings.

Dim i As Long
For i = LBound(nums) To UBound(nums)
  Debug.Print nums(i)
Next i

List (Collection)

VBA doesn’t have a built-in generic List<T> . The most common “list” is Collection .

Topic Examples
Create + add items 
Dim list As Collection
Set list = New Collection
list.Add "Apple"
list.Add "Banana"
Debug.Print list.Count  ' 2
Loop items 
Dim item As Variant
For Each item In list
  Debug.Print item
Next item
Access by index Debug.Print list(1) ' "Apple" (1-based)

Dictionary (Key/Value)

Use Scripting.Dictionary (recommended). In Access: Tools → References → check Microsoft Scripting Runtime (optional but nice for IntelliSense).

Topic Examples
Create + set values 
Dim dict As Object
Set dict = CreateObject("Scripting.Dictionary")

dict("name") = "Phuong"
dict("age") = 25
Debug.Print dict("name")
Check key 
If dict.Exists("age") Then
  Debug.Print dict("age")
End If
Loop keys 
Dim k As Variant
For Each k In dict.Keys
  Debug.Print k & ": " & dict(k)
Next k

ByVal vs ByRef (Parameter Passing)

In VBA, parameters are passed ByRef by default (unless you specify ByVal ).
ByVal = pass a copy (callee can’t change caller variable). ByRef = pass a reference (callee can change caller variable).

Topic Examples
ByVal (copy) 
Public Sub AddTen_ByVal(ByVal n As Long)
  n = n + 10
  Debug.Print "Inside AddTen_ByVal, n=" & n
End Sub

Sub Demo_ByVal()
  Dim x As Long
  x = 5

  AddTen_ByVal x

  Debug.Print "After call, x=" & x  ' still 5
End Sub
ByRef (reference)(default) 
Public Sub AddTen_ByRef(ByRef n As Long)
  n = n + 10
  Debug.Print "Inside AddTen_ByRef, n=" & n
End Sub

Sub Demo_ByRef()
  Dim x As Long
  x = 5

  AddTen_ByRef x

  Debug.Print "After call, x=" & x  ' now 15
End Sub
Rule of thumb:
  • Use ByVal for inputs (safer, avoids surprises).
  • Use ByRef when you intentionally want the procedure to modify a variable / return extra values.

OOP Example – Simple Point Class

A minimal OOP example in VBA using a Point class with X and Y properties and a method to compute distance to the origin.

1) Create Class Module: Point

Point.cls 
Option Explicit

Private mX As Double
Private mY As Double

Public Property Get X() As Double
  X = Me.mX
End Property

Public Property Let X(ByVal value As Double)
  Me.mX = value
End Property

Public Property Get Y() As Double
  Y = Me.mY
End Property

Public Property Let Y(ByVal value As Double)
  Me.mY = value
End Property

Public Function DistanceToOrigin() As Double
  DistanceToOrigin = Sqr(Me.mX ^ 2 + Me.mY ^ 2)
End Function

2) Usage Example (Standard Module)

Module code 
Option Explicit

Public Sub TestPoint()
  Dim p As Point
  Set p = New Point

  p.X = 3
  p.Y = 4

  Debug.Print p.DistanceToOrigin()  ' Output: 5

  Set p = Nothing
End Sub

Access Forms, Controls, and Events

Key idea: In Access VBA, a Form is an object (a class instance).
Controls on a form (TextBox, ComboBox, Button...) are also objects (classes).
When you write code behind a form, you are writing code inside that form’s class module .

Common UI Controls (objects)

Control Notes / Example usage
TextBox Me.txtName.Value = "Loc"
Value is often default; Me.txtName = "Loc" also works
ComboBox Me.cboStatus.Value = "Active"
CommandButton ' user clicks to run code
Label Me.lblInfo.Caption = "Saved!"

Event Handlers (run when user does something)

Event procedures live in the form class module . Access calls them automatically.

Event Example
Form_Load (when form opens) 
Private Sub Form_Load()
  Me.lblInfo.Caption = "Ready"
End Sub
Button_Click 
Private Sub cmdSave_Click()
  ' Example: basic validation
  If Nz(Me.txtName.Value, "") = "" Then
    MsgBox "Name is required."
    Exit Sub
  End If

  DoCmd.RunCommand acCmdSaveRecord
  Me.lblInfo.Caption = "Saved!"
End Sub
TextBox_AfterUpdate 
Private Sub txtName_AfterUpdate()
  Me.lblInfo.Caption = "Name changed: " & Nz(Me.txtName.Value, "")
End Sub

Form Class Module Example

This is what code behind a form can look like (e.g., form named frmCustomer ).

frmCustomer (Form Class Module) 
Option Explicit

Private Sub Form_Load()
  Me.lblInfo.Caption = "Ready"
End Sub

Private Sub cmdClear_Click()
  Me.txtName.Value = Null
  Me.cboStatus.Value = Null
  Me.lblInfo.Caption = "Cleared"
End Sub

Private Sub cmdSave_Click()
  If Nz(Me.txtName.Value, "") = "" Then
    MsgBox "Name is required."
    Exit Sub
  End If

  DoCmd.RunCommand acCmdSaveRecord
  Me.lblInfo.Caption = "Saved!"
End Sub
