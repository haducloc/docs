PART 1 — CLOUD FUNDAMENTALS

What is Cloud Computing?

Cloud computing is the delivery of computing resources over the Internet on demand.

Instead of buying physical servers, organizations rent resources from cloud providers.

Examples:

  • Virtual Machines
  • Storage
  • Databases
  • Networking
  • AI Services
  • Containers
  • Serverless Functions

Benefits:

  • No physical hardware management
  • Pay only for what you use
  • Scale quickly
  • Global availability
  • Built-in redundancy
  • Faster deployment

Mental Model:

Cloud Computing

Renting IT infrastructure and services over the Internet.

PART 3 — CLOUD SERVICE MODELS

IaaS (Infrastructure as a Service)

You Manage:

  • Applications
  • Data
  • Runtime
  • OS

Provider Manages:

  • Servers
  • Networking
  • Storage
  • Datacenter

Examples:

  • AWS EC2
  • Azure VM
  • Google Compute Engine

PaaS (Platform as a Service)

You Manage:

  • Application
  • Code

Provider Manages:

  • Runtime
  • OS
  • Infrastructure

Examples:

  • Azure App Service
  • Google App Engine
  • AWS Elastic Beanstalk

SaaS (Software as a Service)

Provider manages everything.

Examples:

  • Microsoft 365
  • Salesforce
  • Google Workspace
  • ChatGPT

FaaS / Serverless

Run code without managing servers.

Examples:

  • AWS Lambda
  • Azure Functions
  • Google Cloud Functions

PART 37 — INTERVIEW PREPARATION

What is Cloud Computing?

Cloud computing is the on-demand delivery of compute, storage, networking, databases, and managed services over the Internet using a pay-as-you-go model.

What is a VPC?

A logically isolated network inside a cloud provider.

What is Kubernetes?

A platform used to deploy, scale, and manage containers.

What is IAM?

Identity and Access Management.

Controls who can access resources.

Difference Between VM and Container

Vm

  • Own OS
  • Own Kernel

Container

  • Shared Kernel
  • Lightweight

What is High Availability?

Designing systems to continue operating despite failures.
