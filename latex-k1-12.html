LaTeX Cheat Sheet for K1-12

A printable, navigable LaTeX reference for elementary, middle school, and high school math, plus common physics and chemistry formulas. Every code sample includes rendered output.

How to Read This Cheat Sheet

Use inline math for short expressions inside text and display math for centered formulas.

Inline math

\( 2 + 3 = 5 \)
\( 2 + 3 = 5 \)

Display math

\[
2 + 3 = 5
\]
\[2+3=5\]
For web pages, MathJax renders LaTeX in the browser. For printed documents, you can print this page after the formulas finish rendering.
