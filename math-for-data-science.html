Logic supports proofs, programming conditions, database queries, and AI reasoning.

4. Proof Methods

Direct Proof

Show the statement is true directly from definitions and known facts.

Proof by Contradiction

Assume the opposite is true, then show that assumption leads to an impossible result.

Mathematical Induction

  1. Prove the base case.
  2. Assume true for n.
  3. Prove true for n + 1.
AI connection: Proof skills improve your ability to reason about algorithms, convergence, and model assumptions.

5. Algebra

Linear Equation

y = mx + b

m = slope, b = y-intercept.

Slope

m = (y₂ - y₁) / (x₂ - x₁)

Systems of Equations

x + y = 5
x - y = 1
Solution: Add equations: 2x = 6, so x = 3 and y = 2.

Quadratic Equation

ax² + bx + c = 0
x = (-b ± √(b² - 4ac)) / 2a
Example: x² - 5x + 6 = 0 gives x = 2 and x = 3.

Exponent Rules

aᵐaⁿ = aᵐ⁺ⁿ
aᵐ / aⁿ = aᵐ⁻ⁿ
(aᵐ)ⁿ = aᵐⁿ

Logarithms

log_b(x) = y means bʸ = x
Example: log₂(8) = 3 because 2³ = 8.

Natural Log

ln(x) uses base e, where e ≈ 2.71828
AI connection: Logs appear in likelihood, cross-entropy loss, logistic regression, and information theory.

8. Trigonometry

Trigonometry appears in signal processing, Fourier transforms, rotations, and time series.

9. Linear Algebra

This is one of the most important areas for AI. Data, images, embeddings, model weights, and neural networks are all represented with vectors and matrices.

Scalar

5

Vector

v = [1, 2, 3]ᵀ
Real-world example: One person can be represented as a vector: [age, income, credit score].

Matrix

A = [[1, 2], [3, 4]]

A dataset is often a matrix: rows are observations and columns are features.

Matrix Dimensions

m × n = rows × columns

Matrix Addition

Add corresponding entries.

Matrix Multiplication

The number of columns in the first matrix must equal the number of rows in the second matrix.

[1, 2] · [3, 4]ᵀ = 1(3) + 2(4) = 11

Dot Product

a · b = Σ aᵢbᵢ
AI connection: Dot products measure similarity in embeddings, search engines, recommendation systems, and attention mechanisms.

Vector Magnitude

||v|| = √(Σvᵢ²)

Euclidean Distance

d = √(Σ(xᵢ - yᵢ)²)
AI connection: Used in KNN, clustering, anomaly detection, and nearest-neighbor search.

Identity Matrix

I = [[1, 0], [0, 1]]

Matrix Inverse

AA⁻¹ = I

Determinant

For [[a, b], [c, d]], det(A) = ad - bc

The determinant tells whether a matrix is invertible and how much a transformation scales area or volume.

Linear Independence

Vectors are linearly independent if none can be built from the others.

(1,0) and (0,1) are independent. (1,2) and (2,4) are dependent.

Basis

A minimal set of vectors that spans a space.

Span

All possible linear combinations of a set of vectors.

Rank

The number of independent rows or columns.

Null Space

Solutions to Ax = 0

Eigenvalues & Eigenvectors

Av = λv

A matrix transforms an eigenvector only by scaling it.

AI connection: Used in PCA, dimensionality reduction, compression, recommendation systems, and computer vision.

Singular Value Decomposition

A = UΣVᵀ
AI connection: Used in PCA, recommender systems, compression, search, and embeddings.

10. Calculus

Calculus explains how machine learning models learn by changing parameters to reduce error.

Limits

limₓ→ₐ f(x)

Derivative

A derivative measures rate of change.

If f(x) = x², then f'(x) = 2x

Common Derivatives

FunctionDerivative
c0
x1
xⁿnxⁿ⁻¹
eˣeˣ
ln(x)1 / x

Chain Rule

dy/dx = (dy/du)(du/dx)
If y = (3x + 1)², then dy/dx = 6(3x + 1).
AI connection: Backpropagation is repeated use of the chain rule.

Partial Derivatives

∂f / ∂x

Used when a function has multiple variables.

For f(x,y) = x² + y², ∂f/∂x = 2x and ∂f/∂y = 2y.

Gradient

∇f = vector of partial derivatives

The gradient points in the direction of greatest increase.

Jacobian

A matrix of first derivatives. Important for vector-valued functions.

Hessian

A matrix of second derivatives. Useful in optimization and Newton-style methods.

Integration

Integration measures area under a curve.

∫x² dx = x³/3 + C

Fundamental Theorem of Calculus

Connects differentiation and integration.

11. Numerical Methods

Computers often approximate solutions instead of finding exact symbolic answers.

Newton's Method

x_new = x - f(x) / f'(x)

Used to find roots of functions.

Finite Differences

Approximate derivatives numerically.

f'(x) ≈ [f(x+h) - f(x)] / h
AI connection: Numerical approximation helps understand gradients, optimization, and model checking.

12. Probability

Probability is the foundation of uncertainty, statistics, Bayesian reasoning, and machine learning.

Probability

0 ≤ P(A) ≤ 1
For a fair coin, P(head) = 0.5.

Conditional Probability

P(A | B)

Probability of A given B.

Bayes Theorem

P(A | B) = [P(B | A)P(A)] / P(B)
AI connection: Used in spam filtering, medical diagnosis, Bayesian inference, and probabilistic models.

Random Variables

TypeExamples
DiscreteCoin flips, dice rolls, number of clicks.
ContinuousHeight, weight, temperature, time.

Expected Value

E[X] = Σ xP(x)
For a fair die, E[X] = 3.5.

Variance

Var(X) = E[(X - μ)²]

Covariance

Cov(X,Y)

Measures whether two variables move together.

Correlation

-1 ≤ ρ ≤ 1

Standardized covariance.

Law of Large Numbers

As sample size increases, the sample average approaches the true expected value.

Central Limit Theorem

Sample means tend to become normally distributed as sample size increases.

13. Statistics

Population vs Sample

Population: entire group. Sample: subset of the group.

Mean

Median

Middle value.

Mode

Variance

Standard Deviation

s = √s²

Z-Score

z = (x - μ) / σ

14. Distributions

Normal Distribution

Bell curve. Important rule:

  • 68% within 1 standard deviation
  • 95% within 2 standard deviations
  • 99.7% within 3 standard deviations

Uniform Distribution

All outcomes are equally likely.

Bernoulli Distribution

Single success/failure trial.

Binomial Distribution

Multiple Bernoulli trials.

Example: Number of heads in 10 coin flips.

Poisson Distribution

Counts events in a fixed interval.

Examples: calls per hour, website visits per minute.

Exponential Distribution

Models time between events.

15. Hypothesis Testing

Null Hypothesis

H₀

Default assumption, usually “no effect” or “no difference.”

Alternative Hypothesis

Hₐ

The claim you are testing for.

p-value

A small p-value gives evidence against H₀. A common threshold is p < 0.05.

Confidence Interval

A range of plausible values for the true population parameter.

Type I Error

False positive.

Type II Error

False negative.

Statistical Power

Probability of detecting a real effect.

16. Information Theory

Entropy

H(X) = -Σ p(x)log p(x)

Measures uncertainty.

A fair coin has higher entropy than a double-headed coin.

Cross Entropy

Measures difference between true labels and predicted probabilities. Used as a neural-network loss function.

KL Divergence

D_KL(P || Q)

Measures how one probability distribution differs from another.

Mutual Information

Measures shared information between variables. Useful for feature selection.

17. Optimization

Optimization is the process of finding the best parameters that minimize a cost function.

Objective / Cost Function

J(θ)

Gradient Descent

θ_new = θ_old - α∇J(θ)

θ = model parameters, α = learning rate.

Learning Rate

Too small: slow learning. Too large: may diverge.

Convex Function

A function where any local minimum is also a global minimum.

Local Minimum

Best point nearby, but not necessarily best overall.

Global Minimum

Best point overall.

Saddle Point

A flat or mixed-curvature point common in deep learning optimization.

Stochastic Gradient Descent

Uses one training example at a time.

Mini-Batch Gradient Descent

Uses small batches. This is common in real machine learning training.
