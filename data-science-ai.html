Data Science is about using data to understand, predict, explain, or automate decisions.

Machine Learning means a model learns patterns from examples instead of being manually programmed.

Deep Learning is machine learning using neural networks.

Generative AI creates new content: text, code, images, audio, video.

AI Agents are AI systems that can reason, call tools, search files, use APIs, write code, or perform multi-step tasks.

4. Model-Building / Training Process

Step 1: Define the problem

QuestionExample
What are we predicting?Fraud or not fraud
Is it classification or regression?Classification
What data is available?Transactions
What is success?Catch 95% of fraud
What is costly?False positives annoy customers

Step 5: Feature engineering

Feature engineering means creating useful inputs.

Raw dataBetter feature
Dateday of week, month, holiday
Login recordslogins last 7 days
Addressdistance to office
TextTF-IDF or embedding
Transaction historyaverage amount, max amount
User actionsnumber of clicks

For traditional ML, feature engineering is very important.

For deep learning and LLMs, models can learn more features automatically, but good input design still matters.

Step 6: Split data

SplitPurpose
Training setFit model
Validation setTune model
Test setFinal unbiased evaluation
 
70% training
15% validation
15% test

For time series, do not randomly shuffle future and past.

past data → train
future data → test

Step 7: Choose baseline model

Always start simple.

ProblemGood baseline
RegressionLinear regression
ClassificationLogistic regression
Tabular dataRandom forest / XGBoost
Text classificationTF-IDF + logistic regression
Forecastingseasonal average
Imagepretrained CNN
Document Q&Abasic RAG

A simple baseline tells you whether complex models are actually helping.

Step 8: Train model

Training means the algorithm adjusts internal parameters to reduce error.

For traditional ML:

model.fit(X_train, y_train)

For deep learning:

for each epoch:
    for each batch:
        predict
        calculate loss
        backpropagate
        update weights

PyTorch tutorials cover loading data, building neural networks, training, visualization, and saving models.

Step 9: Evaluate model

Use metrics that match the business problem.

MetricWhy
RecallCatch fraud
PrecisionAvoid false alarms
F1Balance precision/recall
AUCRanking quality

Do not rely only on accuracy if data is imbalanced.

99% transactions are not fraud.
A model that always says "not fraud" has 99% accuracy.
But it is useless.

Scikit-learn includes tools for model selection, validation, supervised learning, unsupervised learning, preprocessing, and metrics.

5. Types of Machine Learning

A. Supervised Learning

You have examples with correct answers.

Input X → known label y
InputLabel
Email textspam/not spam
House featuresprice
Transactionfraud/not fraud
Imagecat/dog

Use supervised learning when you have historical examples.

Scikit-learn’s supervised learning section includes linear models, SVMs, nearest neighbors, decision trees, ensembles, feature selection, calibration, and neural network models.

B. Unsupervised Learning

You have data but no labels.

TaskExample
Clusteringgroup similar customers
Dimensionality reductioncompress features
Anomaly detectiondetect strange activity
Topic groupinggroup documents

Use unsupervised learning when you want to discover structure.

C. Reinforcement Learning

An agent learns by interacting with an environment.

state → action → reward → new state
Use caseExample
Game AIAlphaGo
Roboticsrobot movement
Routingwarehouse optimization
Adsbidding strategy

Use reinforcement learning when decisions happen over time and rewards come later.

8. Generative AI Concepts

Prompt Engineering

Role: You are a senior data scientist.
Task: Explain XGBoost.
Context: I am a software developer.
Format: Use tables and examples.
Constraints: Avoid heavy math.
PatternExample
Role“Act as a data scientist”
Context“I know Java but not ML”
Task“Explain when to use clustering”
Format“Use table + examples”
Constraints“No heavy math”
Examples“Follow this sample format”

RAG combines search with an LLM.

User asks question
→ retrieve relevant docs
→ send docs to LLM
→ answer using docs

huge knowledge baseyes

Fine-tuning trains an existing model further.

Good useExample

12. Important Concepts

Bias-Variance Tradeoff

ProblemMeaning
High biasmodel too simple
High variancemodel overfits

Regularization

Reduces overfitting.

TypeUsed in
L1Lasso
L2Ridge
Dropoutneural networks
Early stoppingboosting/deep learning

Data Leakage

Data leakage means the model sees information it should not know.

Example: Predict loan default using a field that is only created after default.

This gives fake high accuracy.

Cross-validation

Cross-validation tests a model on multiple train/test splits.

Useful when data is limited.

Class imbalance

Fraud = 1%
Not fraud = 99%

Accuracy becomes misleading.

precision
recall
F1
AUC

17. Simple Decision Tree

Do you have labels?
├── Yes
│   ├── Predict number? → Regression
│   └── Predict category? → Classification
│
├── No
│   ├── Find groups? → Clustering
│   ├── Reduce features? → PCA/UMAP
│   └── Find unusual records? → Anomaly detection
│
├── Need text/code generation?
│   └── LLM
│
├── Need answer from private docs?
│   └── RAG
│
└── Need multi-step tool-using automation?
    └── AI agent
