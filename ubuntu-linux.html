Overview

This document combines all generated topics and commands into one copy-friendly HTML reference. Use the table of contents to jump to a topic, and use the Copy button on any command block.

Each command block now includes comments explaining what the command is for, so the examples are easier to study and reuse.

Safety note: commands such as rm -rf, dd, firewall changes, filesystem repair, and package removal can damage systems if used incorrectly. Verify target paths, devices, and hosts before running them.

SSH Cheat Sheet

Connect

ssh user@server                   # Connects to a server using SSH.
ssh user@192.168.1.100            # Connects to a server by IP address using SSH.
ssh -p 2222 user@server           # Connects to SSH on custom port 2222.

Run Remote Command

ssh user@server "df -h"           # Runs disk usage check on a remote server over SSH.
ssh user@server "systemctl status nginx" # Checks nginx status on a remote server over SSH.

Login with Key

ssh -i ~/.ssh/id_rsa user@server  # Connects using a specific private key file.

Verbose Debugging

ssh -v user@server                # Connects with basic verbose debugging.
ssh -vv user@server               # Connects with more detailed SSH debugging.
ssh -vvv user@server              # Connects with maximum SSH debugging detail.

Port Forwarding - Local Forward

ssh -L 8080:localhost:80 user@server # Creates a local port forward from local 8080 to remote localhost:80.

Port Forwarding - Remote Forward

ssh -R 8080:localhost:80 user@server # Creates a remote port forward from server 8080 to local localhost:80.

SOCKS Proxy

ssh -D 1080 user@server           # Creates a SOCKS proxy on local port 1080 through SSH.

SSH Config

vi ~/.ssh/config                  # Edits the SSH client configuration file.

Example Config

Host prod
    HostName 10.10.10.5
    User admin
    Port 2222
    IdentityFile ~/.ssh/prod.pem

Then

ssh prod                          # Connects using the Host alias named prod from SSH config.

Curl Cheat Sheet

GET Request

curl https://google.com           # Fetches the web page content from google.com.

Save Output

curl -o file.html URL             # Downloads a URL and saves it as file.html.
curl -O URL                       # Downloads a URL and saves it using the remote filename.

Follow Redirects

curl -L URL                       # Follows HTTP redirects while downloading.

Show Headers

curl -I URL                       # Fetches only HTTP response headers.

Verbose

curl -v URL                       # Runs curl with verbose connection details.

REST API Calls - GET

curl https://api.example.com/users # Sends a GET request to an API endpoint.

REST API Calls - POST

curl -X POST https://api.example.com/users # Sends an HTTP POST request to an API endpoint.

POST JSON

# Sends a JSON POST request to create or submit data to an API.
curl -X POST \
-H "Content-Type: application/json" \
-d '{"name":"John"}' \
https://api.example.com/users

PUT

# Sends a PUT request to update an API resource.
curl -X PUT \
-d '{"name":"Bob"}' \
https://api.example.com/users/1

DELETE

curl -X DELETE https://api.example.com/users/1 # Sends an HTTP DELETE request to remove a resource.

Authentication - Basic Auth

curl -u user:password URL         # Sends a request using HTTP Basic authentication.

Bearer Token

# Sends a request with a Bearer token for API authentication.
curl \
-H "Authorization: Bearer TOKEN" \
URL

API Key

# Sends a request with an API key header for authentication.
curl \
-H "x-api-key: KEY" \
URL

Upload File

curl -F "file=@test.txt" URL      # Uploads a file using multipart/form-data.

Download with Resume

curl -C - -O URL                  # Resumes an interrupted download and saves using the remote filename.

Quick Admin One-Liners

Test Website

curl -I https://example.com       # Checks HTTP response headers for a website.

Test SSL

openssl s_client -connect example.com:443 # Tests SSL/TLS certificate and handshake for example.com.

Check Port

nc -zv example.com 443            # Checks whether HTTPS port 443 is open.

Download and Execute

curl -fsSL URL | bash             # Downloads a script and runs it with bash; use only from trusted sources.

Be careful with this one.

SSH Without Host Verification

ssh -o StrictHostKeyChecking=no user@host # Connects without prompting for host key verification, reducing security.

Copy Key Automatically

ssh-copy-id user@host             # Installs your public SSH key on a remote user account.

Remote Disk Usage

ssh server "df -h"                # Checks disk usage on a remote server over SSH.

Remote Restart Service

ssh server "sudo systemctl restart nginx" # Restarts nginx on a remote server using sudo over SSH.

Check Public IP

curl ifconfig.me                  # Shows the public IP address seen by the internet.

Check HTTP Response Time

curl -o /dev/null -s -w "%{time_total}\n" URL # Measures total HTTP request time without printing the response body.

Download Entire Directory Tree

wget -r URL                       # Downloads a website or directory tree recursively.

These commands alone probably account for 50-70% of what Linux admins do when managing remote servers every day. SSH, rsync, curl, dig, tcpdump, journalctl, systemctl, and ss are the power tools most admins keep in muscle memory.
